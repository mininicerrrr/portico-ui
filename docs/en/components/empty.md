# Empty

Empty-state placeholder. Default copy comes from the locale; override it with `description`, the `image` slot, and the default action slot.

## Basic usage

<DemoBox>
  <pt-empty>
    <pt-button type="primary">Reload</pt-button>
  </pt-empty>
</DemoBox>

## API

### Props

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| description | Description | `string` | 语言包默认值 |
