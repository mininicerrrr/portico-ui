# Internationalization

The default locale is Simplified Chinese (`zh-CN`). An English pack (`en`) is also shipped. Inject a locale through the plugin or `PtConfigProvider` instead of relying on hardcoded copy.

## Plugin option

```ts
import { createApp } from 'vue'
import PorticoUI, { en, zhCN } from 'portico-ui'
import 'portico-ui/style.css'

createApp(App).use(PorticoUI, { locale: en }).mount('#app')
```

## Scoped override

```vue
<script setup>
import { en } from 'portico-ui'
</script>

<template>
  <pt-config-provider :locale="en">
    <pt-select :options="[]" />
  </pt-config-provider>
</template>
```

Individual components also accept copy overrides such as Select `placeholder`, `loadingText`, `noMatchText`, `noDataText`, and Table `emptyText`.
