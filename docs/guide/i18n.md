# 国际化

库的默认语言是简体中文（`zh-CN`），同时内置英文包 `en`。不要在业务里依赖组件源码中的固定文案；通过插件选项或 `PtConfigProvider` 注入语言包。

## 插件配置

```ts
import { createApp } from 'vue'
import PorticoUI, { en, zhCN } from 'portico-ui'
import 'portico-ui/style.css'

createApp(App).use(PorticoUI, { locale: zhCN }).mount('#app')
```

## 局部覆盖

```vue
<script setup>
import { en } from 'portico-ui'
</script>

<template>
  <pt-config-provider :locale="en">
    <pt-select :options="[]" />
  </pt-config-provider>
</template>
```

覆盖单个组件文案时，也可以传入相应 props，例如 Select 的 `placeholder`、`loadingText`、`noMatchText`、`noDataText`，以及 Table 的 `emptyText`。
